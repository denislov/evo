# DeepSeek Responses fixtures

These SSE fixtures were captured from `https://api.deepseek.com/v1/responses`
with `deepseek-v4-flash` on 2026-08-02. Response, item, and call identifiers
were replaced with deterministic test identifiers. Natural-language deltas
were shortened, while event names, ordering, item shapes, terminal response
fields, and usage detail shapes were preserved.

No request authorization headers or API keys are stored in this directory.
